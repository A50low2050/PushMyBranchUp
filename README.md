# PushMyBranchUp

Мини-соцсеть для группы

## Запуск проекта

Для начала клонируем проект и создаем виртуальное окружение и установить библиотеки.

```bash
# Клонируем проект
git clone https://github.com/A50low2050/PushMyBranchUp.git
# создаём виртуальное окружение
python -m venv .venv
# активируем его
.venv\Scripts\activate
# устанавливаем библиотеки
pip install -r requirements.txt
```

Далее создаём `.env` файл на основе `.env.example`.

```bash
# конфигурация для uvicorn
ENV_UVICORN__HOST=localhost
ENV_UVICORN__PORT=8888
ENV_UVICORN__RELOAD=True

# URL для подключения к SQLite
ENV_DATABASE__URL=sqlite+aiosqlite:///./db.sqlite3
```

Далее нужно установить хуки для утилиты pre-commit, чтобы автоматически проверять код до того, как он будет опубликован в git.

```bash
# устанавливаем хуки для pre-commit
pre-commit install --hook-type pre-commit --hook-type pre-push
# можно вручную запустить хуки
pre-commit run --all-files
```

Сам pre-commit использует статический анализатор mypy, линтер flake8 и форматтер black. Для их запуска можно прописать следующие команды.

```bash
# запустить анализ типов для src/
mypy src/
# запустить линтер кода для src/
flake8 src/
# запустить форматтер кода для src/
black src/
```

После всех процедур можно запустить приложение.

```bash
# запускаем приложение
python ./src/main.py
```

## Структура проекта

Проект работает по адресу http://localhost:8888. Документация доступна по адресу `http://localhost:8888/docs/`. Адрес может меняться в зависимости от указанного в конфигурации порта `uvicorn`.

```bash
pmbu/
├── .env.example                 # шаблон переменных окружения (секреты, пути, настройки)
├── .env                         # локальный файл конфигурации (не коммитится в git)
├── .gitignore                   # исключения для Git (__pycache__, *.db, .env, .venv)
├── .pre-commit-config.yaml      # pre-commit хуки для проверки кода перед коммитом и пушем в гит
├── README.md                    # инструкция по установке, запуску и прогону тестов
├── requirements.txt             # зависимости Python (FastAPI, SQLAlchemy, PyJWT, pytest и др.)
├── setup.cfg                    # конфигурация для mypy, flake8 и black
├── logconfig.json               # конфигурация для логгирования приложения
├── db.sqlite3                   # SQLite база данных приложения (появляется после первого запуска)
├── alembic.ini                  # конфигурация для миграций alembic
│
└── src/                         # основной исходный код приложения
    │
    ├── main.py                  # точка входа приложения (запускаем именно этот файл)
    ├── config.py                # конфигурация приложения (чтение .env и прочие параметры)
    │
    ├── api/                     # API слой для приложения
    │   ├── __init__.py
    │   ├── main.py              # создание и инициализация FastAPI приложения
    │   └── v1/
    │       ├── errors.py        # кастомные HTTP ошибки
    │       └── deps/            # зависимости для FastAPI для переиспользования
    │       └── routes/          # эндпоинты API
    │
    ├── db/                      # конфигурация для работы с БД
    │   ├── __init__.py
    │   ├── connection.py        # подключение к БД (создание движка и фабрики сессий)
    │   └── manager.py           # служеюный класс DBManager для работы с репозиториями и управления сессией
    │
    ├── migrations/              # директория для миграций через alembic (создано автоматически)
    │   ├── env.py               # конфигурация Alembic (сюда нужно импортировать ORM модели при создании)
    │   └── versions/            # файлы миграций
    │
    ├── repos/                   # слой доступа к данным
    │   └── base.py              # базовый репозиторий с CRUD методами для работы с БД
    │
    ├── services/                # слой бизнес-логики
    │   └── base.py              # базовый класс, от которого нужно наследоваться
    │
    ├── models/                  # ORM модели приложения
    │   └── base.py              # базовый ORM клас
    │
    ├── schemas/                 # DTO схемы данных для передачи между слоями
    │   └── base.py              # базовый DTO класс
    │ 
    ├── tests/                   # директория для хранения автотестов
    │
    └── utils/                   # вспомогательные утилиты и файлы
        ├── logserv.py           # отдельный сервис прокси для логирования
        └── exceptions.py        # иерархия доменных исключений
```
